= spring-versions

A zsh plugin that shows the currently supported OSS and commercial versions of a Spring project, grouped by support type.

== Overview

Spring project pages (e.g. https://spring.io/projects/spring-security#support) list which release generations are currently supported: an OSS support window, a longer commercial (Tanzu/Enterprise) support window, and the current patch version per generation. This plugin fetches that same data from the official https://github.com/spring-io/projects-api[spring-io/projects-api] (deployed at `https://api.spring.io`) for the Spring project the current directory belongs to, and prints it without needing a browser.

== Features

* Groups generations into `OSS` (still within its OSS support window) and `COMMERCIAL` (OSS window closed, commercial support still active)
* Drops generations whose commercial support has already ended
* Shows the current patch version and the branch for each generation (the newest OSS generation is `main`)
* Defaults the project to the current directory's git remote, but accepts an explicit override
* Tab-delimited text output by default, or JSON with `--json`
* Optional `--type` filter to show only OSS or only commercial generations
* Optional `--field` to print just one field's values, one per line
* Zsh tab completion for all options and their values

== Installation

Can be installed using antigen:

[source,bash]
----
antigen bundle rwinch/zsh-plugins/spring-versions
----

Or manually by adding the plugin directory to your `PATH`.

== Usage

[source,bash]
----
spring-versions [OPTIONS]
----

=== Options

* `-p, --project SLUG` - Spring project slug (e.g. `spring-security`). Default: the final path segment of a remote URL (a trailing `-commercial` is stripped). The remote used is the current branch's tracked remote, falling back to `origin`, then a remote whose name starts with `spring-`.
* `-t, --type TYPE` - Only show one support type: `oss`/`o` or `commercial`/`c`. Default: show both, grouped.
* `--json` - Output as JSON instead of the default tab-delimited text.
* `-f, --field FIELD` - Print one raw value per line for the given field across all matching generations (after any `--type` filter), instead of the normal table/JSON output. `FIELD` is one of: `generation`, `branch`, `currentVersion`, `ossSupportEnd`, `commercialSupportEnd`, `type`. Shortcut for `spring-versions --json | jq -r '.[].FIELD'`.
* `-h, --help` - Show the help message.

=== Examples

[source,bash]
----
# Derive the project from the current directory's git remote
spring-versions

# Look up a specific project regardless of the current directory
spring-versions --project spring-boot

# JSON output
spring-versions --json

# Only the commercially-supported generations
spring-versions --type commercial

# Only OSS-supported generations, as JSON
spring-versions -t o --json

# Just the branch names, one per line
spring-versions --field branch

# Just the branch names of OSS-supported generations
spring-versions -t o -f branch
----

== Requirements

* `curl`
* `jq`
* `git`
* `column` (part of `util-linux`/BSD base tools; present by default on macOS and most Linux distros)

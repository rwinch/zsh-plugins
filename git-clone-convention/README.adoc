= git-clone-convention

A zsh plugin that provides `clone`, which clones a Git repository into `~/code/${owner}/${repository}/${branch}`, names the remotes so that the OSS and commercial repositories line up with the other tools here (`oss` and `commercial`), and changes into the clone.

== Features

* Clones into `~/code/${owner}/${repository}/${branch}`, named after the repository's actual default branch
* When `${owner}/${repository}-commercial` exists as a private repository, the remotes are `oss` (the clone) and `commercial` (added and fetched after the clone), the names link:../gh-milestones[gh-milestones] and the link:../git-branches[git-branches] commands expect
* Otherwise the remote is named after the owner instead of `origin`
* Adds your fork (`${login}/${repository}`) as a remote named after your login, when it exists
* When there is a commercial repository and link:../gh-block-embargoed-branches[gh-block-embargoed-branches] is installed, checks that `embargoed/**` branches are blocked in the OSS repository and in your fork, and offers to set that up when they are not (default yes)
* Detects an existing clone and changes into it instead of cloning
* `--dry-run` looks everything up and prints the plan, and changes nothing
* Adds link:https://github.com/mfaerevaag/wd[wd] shortcuts (when `wd` is available)
* Nothing is ever created on GitHub

== Requirements

* `gh` (optional). It is used to find the commercial repository, your login and your fork. Without it, or when it fails (not logged in, no network), those steps are skipped with a warning and the remote is named after the owner.
* `wd` (optional) for the shortcuts.
* link:../gh-block-embargoed-branches[gh-block-embargoed-branches] (optional) for the embargoed branch check. Without it a warning is printed at the end.

== Installation

[source,bash]
----
antigen bundle rwinch/zsh-plugins git-clone-convention
----

`clone` is a function, not a script, so that the `cd` (and the `wd` shortcuts) happen in your current shell. The function runs the `git-clone-convention` script, which does everything else and prints where to go.

== Usage

[source,bash]
----
clone [OPTIONS] OWNER/REPOSITORY|URL [GIT-CLONE-OPTIONS]
----

The repository is the first argument that is not an option (or the value of one): an `OWNER/REPOSITORY` slug or a full SSH or HTTPS URL, with or without `.git`.

|===
|Option |Description

|`--dry-run`
|Look up everything and print the plan. Nothing is cloned. (There is no `-n` because that is `git clone --no-checkout`.)

|`--https`
|Use HTTPS URLs instead of SSH (the default). Also applies to the `commercial` and fork remotes.

|`--host HOST`
|Git host, default `github.com`.

|`--gitlab`
|Shortcut for `--host gitlab.com`.

|`--help`, `-h`
|Show help.
|===

Every other option is passed to `git clone` (`--branch`, `--depth`, `--single-branch`, ...). `clone` chooses the remote name and the directory itself, so `--origin` and a directory argument are rejected.

== Behavior

. *Already cloned*: when `~/code/${owner}/${repository}` exists, `clone` changes into `main`, else `master`, else the repository directory, and does nothing else (no lookups, no remotes, no shortcuts).
. *Lookups* (github.com only, before anything is created): your login, whether `${owner}/${repository}-commercial` exists and is private, and whether `${login}/${repository}` exists (skipped when you are the owner). A repository that is not found is a normal answer. If `gh` is missing or a lookup fails, the lookups are skipped and a warning is printed.
. *Remotes*:
+
|===
|Situation |Remotes

|No commercial repository
|`${owner}`

|Commercial repository
|`oss`, `commercial`

|Fork exists
|plus `${login}`
|===
. *Clone* into `~/code/${owner}/${repository}/main`, then add and fetch `commercial` and the fork. The directory is renamed to the default branch when that is not `main`. If the clone fails, what was created is removed.
. *wd shortcuts*:
** an owner starting with `spring-` gets a shortcut without the prefix to `~/code/${owner}` (`spring-projects` is `projects`)
** a repository starting with `spring-` gets a shortcut without the prefix to the clone (`spring-security` is `security`)
** any other repository gets a shortcut with its full name to the clone
** an existing shortcut with the same name is left alone and a warning is printed
** without `wd`, a note says no shortcuts will be added

== Embargoed branches

After a fresh clone with a commercial repository (that is where `embargoed/**` branches belong), `clone` runs `gh-block-embargoed-branches check` on `${owner}/${repository}` and on your fork (when there is one), never on the commercial repository.

* All protected: nothing more is printed.
* Not protected where you are an admin: one question, `Block embargoed/** branches in A, B now? [Y/n]`. Yes (the default) runs `gh-block-embargoed-branches apply A B`.
* Everything else is a warning printed at the end, after the other output: the command is not installed, you are not an admin of a repository (it names the command an admin should run), the check could not read the rules, you answered no, `apply` failed, or there is no terminal to ask on (the command to run is printed instead).
* `--dry-run` runs the read-only check and reports, but never asks or applies.

[source,bash]
----
$ clone spring-projects/spring-security

Adding remote rwinch: git@github.com:rwinch/spring-security.git
Adding wd shortcut: projects -> ~/code/spring-projects
Adding wd shortcut: security -> ~/code/spring-projects/spring-security/main

----

----
clone --https spring-projects/spring-security

clone spring-projects/spring-security --depth 1
clone git@github.com:spring-projects/spring-security.git
----

== Directory Structure

----
~/code/
  └── ${owner}/
      └── ${repository}/
          └── ${branch}/
----

== Output

The script writes everything meant for people to stderr. Its stdout is for the `clone` function: the directory to change into on the first line, then one `wd<TAB>NAME<TAB>PATH` line for each shortcut to add (`wd addcd PATH NAME`). The script sees `wd` only when `GIT_CLONE_CONVENTION_WD=1` is set, which the function does.

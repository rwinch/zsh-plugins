= git-branches

A group of zsh plugins that work on several branches at once, optionally expanding OSS generations with `--disclosures` into their `disclosure/frozen/<generation>` and `disclosure/active/<generation>` branches. All of them validate everything first, report all problems together, and only link:push[git-branches-push] pushes.

They share the command prefix `git-branches-`, so `git branches-<TAB>` lists them all.

|===
|Command |Alias |Description

|link:fetch[git-branches-fetch] |`gbbf` |Fetch the remotes behind the branches and report how each compares to its upstream
|link:pull[git-branches-pull] |`gbbpl` |Fast-forward the branches to their upstream
|link:reset-to-upstream[git-branches-reset-to-upstream] |`gbbrtu` |Hard reset the branches to their upstream
|link:check-merged[git-branches-check-merged] |`gbbcm` |Check that a chain of branches is merged forward
|link:merge-forward[git-branches-merge-forward] |`gbbmf` |Merge a chain of branches forward
|link:embargoed-create[git-branches-embargoed-create] |`gbbec` |Create `embargoed/frozen` and `embargoed/active` branches from OSS branches, with the commercial remote as upstream
|link:release[git-branches-release] |`gbbr` |Rebuild `release/<version>` branches on their disclosure base
|link:push[git-branches-push] |`gbbph` |Push the branches that are ahead of their upstream
|===

A typical run goes fetch, pull (or reset-to-upstream), check-merged, merge-forward, push, then release.

== Installation

Load all eight:

[source,bash]
----
antigen bundle rwinch/zsh-plugins git-branches
----

Or load only some, by bundling the subfolders:

[source,bash]
----
antigen bundle rwinch/zsh-plugins git-branches/fetch
antigen bundle rwinch/zsh-plugins git-branches/pull
----

Loading the group and a subfolder together is harmless, it only repeats a `PATH` entry and an alias.

== Filling in the arguments

The `svaob` alias (link:../spring-versions[spring-versions]) prints the OSS branches on one line, for example `7.0.x 7.1.x main`:

[source,bash]
----
gbbf $(svaob)
gbbmf $(svaob)
----

Functions fill in `$(svaob)` for you and pass any extra options on: `gbbfa` for `gbbf`, `gbbpla` for `gbbpl`, `gbbpha` for `gbbph`, `gbbrtua` for `gbbrtu` and `gbbcma` for `gbbcm`, `gbbmfa` for `gbbmf` and `gbbeca` for `gbbec` do the same. Except for `gbbeca`, they also add `--disclosures`, so the disclosure branches are included by default, and `--no-disclosures` leaves them out, for example `gbbfa --no-disclosures`.

== Aliases

All aliases start with `gbb`. The prefix is deliberate, to avoid collisions with the aliases of the oh-my-zsh `git` plugin:

* `gb*` is `git branch` (`gb`, `gba`, `gbd`, `gbl`, `gbm`, `gbr`, `gbs`, ...), so `gb` plus a letter would shadow or be shadowed by them
* `gbs*` is `git bisect` (`gbs`, `gbsb`, `gbsg`, `gbsn`, `gbso`, `gbsr`, `gbss`), so `gbs` plus a letter (for BrancheS) would collide, for example `gbsr` is `git bisect reset`
* `gbb*` is not used by the `git`, `gradle`, `mvn`, `wd`, `github` or `extract` plugins

Before adding another letter, check for a clash:

[source,bash]
----
alias | grep '^gbb'
grep -E "^alias gbb" ~/.antigen/bundles/robbyrussell/oh-my-zsh/plugins/git/git.plugin.zsh
----

== Tests

Every plugin has its own suite, for example `zsh fetch/test/test.sh`. To run all of them:

[source,bash]
----
for t in git-branches/*/test/test.sh; do zsh $t | tail -1; done
----

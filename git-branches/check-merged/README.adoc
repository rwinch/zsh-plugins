= git-branches-check-merged

A zsh plugin that checks that a chain of branches is merged forward, on the local branches, on their remote tracking equivalents, or both. It takes the same chain and `--embargoed` arguments as link:../merge-forward[git-branches-merge-forward], link:../pull[git-branches-pull] and link:../reset-to-upstream[git-branches-reset-to-upstream].

== Features

* `git branches-check-merged 7.0.x 7.1.x main` checks that `7.0.x` is contained in `7.1.x`, and `7.1.x` in `main`
* `--embargoed` checks the same hops as `git-branches-merge-forward --embargoed`
* `--local` (the default) checks the local branches, `--remote` checks their upstream refs, and both can be combined
* Read-only: nothing is fetched and nothing is changed, and worktrees may be dirty. Run `git fetch` first to check what is on the remote now.
* Exits 0 when everything is merged and 1 otherwise, and lists the commits that are not merged
* Problems (missing branch, missing upstream, missing remote ref) are collected and reported together

== Installation

[source,bash]
----
antigen bundle rwinch/zsh-plugins git-branches/check-merged
----

The plugin also defines the alias `gbbcm` for `git-branches-check-merged`. See link:../README.adoc#aliases[the group README] for how the `gbb` prefix avoids alias collisions.

To fill in the branches, use the `svaob` alias of link:../../spring-versions[spring-versions] (the OSS branches on one line):

[source,bash]
----
gbbcm $(svaob)
----

The alias function `gbbcma` runs that, adds `--embargoed` unless you give `--no-embargoed`, and passes any extra options on, for example `gbbcma --no-embargoed`.

== Usage

[source,bash]
----
git branches-check-merged [OPTIONS] BRANCH1 BRANCH2 [BRANCH3 ...]
git branches-check-merged [OPTIONS] --embargoed GENERATION [GENERATION ...]
----

|===
|Option |Description

|`--local`, `-l`
|Check the local branches. This is the default when neither `--local` nor `--remote` is given.

|`--remote`, `-R`
|Check the upstream (remote tracking) branches, as of the last fetch. Can be combined with `--local`.

|`--embargoed`, `-e`
|Arguments are OSS generations. Checks the hops `git-branches-merge-forward --embargoed` would merge.

|`--help`, `-h`
|Show help.
|===

== Output

[source,text]
----
$ git branches-check-merged --embargoed 7.0.x main
Checking local branches:
  (1) 7.0.x                   -> main                      merged
  (3) main                    -> embargoed/frozen/main    NOT MERGED, 2 commit(s)
        git log --oneline embargoed/frozen/main..main
        a1b2c3d Fix thing
        e4f5a6b Other fix

Error: 1 of 7 check(s) not merged (local).
----

With `--remote` the names are the upstream refs (`oss/7.0.x -> oss/main`). A branch that is not merged lists up to five of the commits.

== Examples

[source,bash]
----
git branches-check-merged 7.0.x 7.1.x main
git branches-check-merged --remote --embargoed 7.0.x main
git branches-check-merged -l -R -d 7.0.x main
----

= git-branches-pull

A zsh plugin that fast-forwards several branches to their remote tracked branches in one go, across git worktrees, with `--disclosures` and `--releases` support like link:../merge-forward[git-branches-merge-forward] and link:../reset-to-upstream[git-branches-reset-to-upstream].

== Features

* `git branches-pull 7.0.x main` fetches, then fast-forwards each branch to its upstream
* `--disclosures` also pulls `disclosure/frozen/<generation>` and `disclosure/active/<generation>`
* `--releases` also pulls `release/<version>`
* A branch checked out in a worktree is fast-forwarded there (`git merge --ff-only`), any other branch is moved with `git branch -f`
* Never creates merge commits and never discards local commits
* A branch that is only ahead of its upstream is skipped
* `--dry-run` fetches, validates and prints the plan, and changes nothing
* Everything is validated first (branch exists, has an upstream, not diverged, worktree clean) and all problems are reported together
* Use link:../reset-to-upstream[git-branches-reset-to-upstream] for diverged branches

== Installation

[source,bash]
----
antigen bundle rwinch/zsh-plugins git-branches/pull
----

The plugin also defines the alias `gbbp` for `git-branches-pull`. See link:../README.adoc#aliases[the group README] for how the `gbb` prefix avoids alias collisions.

== Usage

[source,bash]
----
git branches-pull [OPTIONS] BRANCH [BRANCH ...]
git branches-pull [OPTIONS] --disclosures GENERATION [GENERATION ...]
git branches-pull [OPTIONS] --releases VERSION[,VERSION ...]
----

|===
|Option |Description

|`--dry-run`, `-n`
|Fetch, validate and print the plan. Nothing is pulled.

|`--disclosures`, `-d`
|Arguments are OSS generations. Each is pulled with its disclosure frozen and active branches. `--disclosure` is accepted too.

|`--releases`, `-r LIST`
|Comma separated release versions, for example `7.0.1,7.0.1.1,7.1.0-RC1`.

|`--help`, `-h`
|Show help.
|===

== Examples

[source,bash]
----
git branches-pull 7.0.x main
git branches-pull --dry-run --disclosures 7.0.x 7.1.x main
git branches-pull -d 7.0.x main -r 7.0.1.1
----

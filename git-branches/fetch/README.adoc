= git-branches-fetch

A zsh plugin that fetches the remotes behind several branches and reports how each branch compares to its upstream, with `--embargoed` support like link:../pull[git-branches-pull] and link:../reset-to-upstream[git-branches-reset-to-upstream].

== Features

* `git branches-fetch 7.0.x main` fetches each branch's upstream remote (once per remote, with `--prune`), then prints whether each branch is up to date, behind, ahead, diverged or gone
* `--embargoed` also reports `embargoed/frozen/<generation>` and `embargoed/active/<generation>`
* Never changes a local branch, worktree or file, so dirty worktrees are fine
* A diverged branch or an upstream that is gone is reported, not an error
* Branches are validated first (exists locally, has an upstream) and all problems are reported together before anything is fetched
* Follow up with link:../pull[git-branches-pull] to fast-forward the branches that are behind

== Installation

[source,bash]
----
antigen bundle rwinch/zsh-plugins git-branches/fetch
----

The plugin also defines the alias `gbbf` for `git-branches-fetch`. See link:../README.adoc#aliases[the group README] for how the `gbb` prefix avoids alias collisions.

To fill in the branches, use the `svaob` alias of link:../../spring-versions[spring-versions] (the OSS branches on one line):

[source,bash]
----
gbbf $(svaob)
----

The alias function `gbbfa` runs that, adds `--embargoed` unless you give `--no-embargoed`, and passes any extra options on, for example `gbbfa --no-embargoed`.

== Usage

[source,bash]
----
git branches-fetch [OPTIONS] BRANCH [BRANCH ...]
git branches-fetch [OPTIONS] --embargoed GENERATION [GENERATION ...]
----

|===
|Option |Description

|`--embargoed`, `-e`
|Arguments are OSS generations. Each is reported with its embargoed frozen and active branches.

|`--help`, `-h`
|Show help.
|===

== Example

[source,bash]
----
$ git branches-fetch -d 7.0.x main
Fetching 'origin'...
Fetching 'oss'...

Fetched (upstream state after fetch):
  7.0.x                        oss/7.0.x                        behind 3
  embargoed/frozen/7.0.x      oss/embargoed/frozen/7.0.x      up to date
  embargoed/active/7.0.x      oss/embargoed/active/7.0.x      behind 1
  main                         origin/main                      ahead 2
  embargoed/frozen/main       oss/embargoed/frozen/main       up to date
  embargoed/active/main       oss/embargoed/active/main       diverged (2 local, 5 upstream)

Fetched 2 remote(s), 6 branch(es): 2 behind, 1 ahead, 1 diverged, 2 up to date.
----

= git-branches-disclosure-create

A zsh plugin that creates the `disclosure/frozen/<generation>` and `disclosure/active/<generation>` branches of new OSS generations, with their upstream set to the commercial remote. It never pushes: it prints the `git push --atomic` command.

== Features

* `git branches-disclosure-create 7.2.x main` creates `disclosure/frozen/7.2.x`, `disclosure/active/7.2.x`, `disclosure/frozen/main` and `disclosure/active/main`, each at the sha of `oss/<generation>`
* The upstream of each branch is the same branch on the commercial remote. That branch does not exist yet, so link:../fetch[git-branches-fetch] reports it as gone until the printed push is done
* `--oss-remote` and `--commercial-remote` choose other remote names (defaults `oss` and `commercial`)
* `--dry-run` validates and prints the plan, and creates nothing
* Never fetches: run link:../fetch[git-branches-fetch] first
* Everything is validated first and all problems are reported together: both remotes exist, `oss/<generation>` exists, the local branches do not exist, and the commercial branches do not exist (those should be tracked with `git branch --track` instead)

== Installation

[source,bash]
----
antigen bundle rwinch/zsh-plugins git-branches/disclosure-create
----

The plugin also defines the alias `gbbdc` for `git-branches-disclosure-create`. See link:../README.adoc#aliases[the group README] for how the `gbb` prefix avoids alias collisions.

To fill in the OSS branches, use `gbbdca`, which runs `gbbdc $(svaob)` (the `svaob` alias of link:../../spring-versions[spring-versions]) and passes any extra options on. Generations that already have disclosure branches are reported as problems, so use it only when all of them are new, otherwise name the new generations:

[source,bash]
----
gbbdca --dry-run
gbbdc 7.2.x main
----

== Usage

[source,bash]
----
git branches-disclosure-create [OPTIONS] GENERATION [GENERATION ...]
----

|===
|Option |Description

|`--oss-remote REMOTE`
|The OSS remote (default `oss`)

|`--commercial-remote REMOTE`
|The commercial remote (default `commercial`)

|`--dry-run`, `-n`
|Validate and print the plan. Nothing is created.

|`--help`, `-h`
|Display the help message
|===

== Example

----
$ gbbdc 7.2.x main
Creating:
  disclosure/frozen/7.2.x  at oss/7.2.x  (a1b2c3d)  upstream commercial/disclosure/frozen/7.2.x (not pushed yet)
  disclosure/active/7.2.x  at oss/7.2.x  (a1b2c3d)  upstream commercial/disclosure/active/7.2.x (not pushed yet)
  disclosure/frozen/main   at oss/main   (e4f5a6b)  upstream commercial/disclosure/frozen/main (not pushed yet)
  disclosure/active/main   at oss/main   (e4f5a6b)  upstream commercial/disclosure/active/main (not pushed yet)

Created 4 branch(es). Push them to create the upstream branches:
  git push --atomic commercial disclosure/frozen/7.2.x disclosure/active/7.2.x disclosure/frozen/main disclosure/active/main
----

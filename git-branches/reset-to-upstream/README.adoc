= git-branches-reset-to-upstream

A zsh plugin that hard resets branches to their remote tracked branches, across git worktrees, with `--disclosures` support like link:../merge-forward[git-branches-merge-forward].

== Features

* `git branches-reset-to-upstream 7.0.x main` resets each branch to its upstream as of the last fetch (nothing is fetched, run `git-branches-fetch` first)
* `--disclosures` also resets `disclosure/frozen/<generation>` and `disclosure/active/<generation>`
* A branch checked out in a worktree is reset there, any other branch is moved with `git branch -f`
* `--dry-run` validates and prints the plan, and changes nothing
* Everything is validated first (branch exists, has an upstream, worktree clean) and all problems are reported together
* The SHAs of discarded local commits are printed so they can be recovered
* `--undo` moves every branch back to where it was before its most recent reset, found in the branch reflog. A branch that has moved since is a problem unless `--force-undo` is used, and a branch with no reset in its reflog is skipped. `--dry-run` works with it
* Nothing is pushed

== Installation

[source,bash]
----
antigen bundle rwinch/zsh-plugins git-branches/reset-to-upstream
----

The plugin also defines the alias `gbbrtu` for `git-branches-reset-to-upstream`. See link:../README.adoc#aliases[the group README] for how the `gbb` prefix avoids alias collisions.

To fill in the branches, use the `svaob` alias of link:../../spring-versions[spring-versions] (the OSS branches on one line):

[source,bash]
----
gbbrtu $(svaob)
----

`gbbrtua` does that for you and passes any extra options on, so `gbbrtua --dry-run` previews a reset of every OSS branch, and `gbbrtua --undo` restores them.

== Usage

[source,bash]
----
git branches-reset-to-upstream [OPTIONS] BRANCH [BRANCH ...]
git branches-reset-to-upstream [OPTIONS] --disclosures GENERATION [GENERATION ...]
----

|===
|Option |Description

|`--dry-run`, `-n`
|Fetch, validate and print the plan. Nothing is reset.

|`--disclosures`, `-d`
|Arguments are OSS generations. Each is reset with its disclosure frozen and active branches. `--disclosure` is accepted too.

|`--undo`, `-u`
|Move every branch back to where it was before its most recent reset by this command (from the branch reflog). A branch that has moved since is a problem and nothing is undone. A branch with no reset in its reflog is skipped. Takes the same arguments, and honors `--dry-run`.

|`--force-undo`
|Like `--undo`, but also restores branches that have moved since the reset, discarding the commits made since.

|`--help`, `-h`
|Show help.
|===

== Examples

[source,bash]
----
git branches-reset-to-upstream 7.0.x main
git branches-reset-to-upstream --dry-run --disclosures 7.0.x 7.1.x main
git branches-reset-to-upstream --undo --dry-run 7.0.x main
git branches-reset-to-upstream --undo 7.0.x main
----

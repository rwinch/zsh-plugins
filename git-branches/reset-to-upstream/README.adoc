= git-branches-reset-to-upstream

A zsh plugin that hard resets branches to their remote tracked branches, across git worktrees, with `--disclosures` and `--releases` support like link:../merge-forward[git-branches-merge-forward].

== Features

* `git branches-reset-to-upstream 7.0.x main` fetches, then resets each branch to its upstream
* `--disclosures` also resets `disclosure/frozen/<generation>` and `disclosure/active/<generation>`
* `--releases` also resets `release/<version>`
* A branch checked out in a worktree is reset there, any other branch is moved with `git branch -f`
* `--dry-run` fetches, validates and prints the plan, and changes nothing
* Everything is validated first (branch exists, has an upstream, worktree clean) and all problems are reported together
* The SHAs of discarded local commits are printed so they can be recovered
* Nothing is pushed

== Installation

[source,bash]
----
antigen bundle rwinch/zsh-plugins git-branches/reset-to-upstream
----

The plugin also defines the alias `gbbrtu` for `git-branches-reset-to-upstream`. See link:../README.adoc#aliases[the group README] for how the `gbb` prefix avoids alias collisions.

To fill in the branches and releases, use the `svaob` alias of link:../../spring-versions[spring-versions] (the OSS branches on one line) and the `ghmr` alias of link:../../gh-milestones[gh-milestones] (this month's milestones as a comma separated list for `--releases`):

[source,bash]
----
gbbrtu $(svaob) --releases $(ghmr)
----

== Usage

[source,bash]
----
git branches-reset-to-upstream [OPTIONS] BRANCH [BRANCH ...]
git branches-reset-to-upstream [OPTIONS] --disclosures GENERATION [GENERATION ...]
git branches-reset-to-upstream [OPTIONS] --releases VERSION[,VERSION ...]
----

|===
|Option |Description

|`--dry-run`, `-n`
|Fetch, validate and print the plan. Nothing is reset.

|`--disclosures`, `-d`
|Arguments are OSS generations. Each is reset with its disclosure frozen and active branches. `--disclosure` is accepted too.

|`--releases`, `-r LIST`
|Comma separated release versions, for example `7.0.1,7.0.1.1,7.1.0-RC1`.

|`--help`, `-h`
|Show help.
|===

== Examples

[source,bash]
----
git branches-reset-to-upstream 7.0.x main
git branches-reset-to-upstream --dry-run --disclosures 7.0.x 7.1.x main
git branches-reset-to-upstream -d 7.0.x main -r 7.0.1.1
----
